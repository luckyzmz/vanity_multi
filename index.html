02

爆破流水线 / PIPELINE

GPU 上每个线程独立跑完整条派生链：计数器混合 secret 生成熵 → 助记词 → 种子 → 子私钥 → 公钥 → 地址 → 前缀比对。命中用 atomicCAS 抢槽落盘，一批跑满才刷新速率——所以显示的每一个数字都是真实吞吐。

STEP 01

熵生成 ENTROPY

SHA256(secret ‖ counter) 取前 16 字节。secret 首次运行自动生成、永不打印，决定整条助记词序列。

STEP 02

助记词 BIP39

熵 → 12 词助记词（2048 词表），再经 PBKDF2-HMAC-SHA512 2048 轮拉伸出种子。

STEP 03

派生 BIP32 / SLIP-10

按各链 BIP44 路径逐层 CKD 派生子私钥，一个助记词可派生 nidx 个索引地址。

STEP 04

公钥与地址 CURVE

secp256k1 或 ed25519 标量乘，再按链规则编码：hex / Base58Check / bech32(m)。

STEP 05

比对落盘 MATCH

前缀命中立即无缓冲追加写入 hits 文件，强杀不丢；搜索不停，Ctrl+C 才退出。

为什么这组数字可信

速率造假最常见的地方，这个项目专门修过

  • 早期版本 kernel 开头有一句 if (*d_found) return;——一个线程命中，整批提前退出，主机端却按整批计数，短前缀时速率虚高约 6.6 倍（显示 2M、实际 340K）。终版已删除，每批跑满，速率即真实吞吐。
  • 五条链内置 selftest：secp256k1 三链核对 11 行已知曲线向量，SOL 系打印 10 pass / 12 pass 显式结论，不联网、不跑搜索就能验。
  • eth test 输出 BIP39 官方向量：熵 00×16 → abandon … about，与标准逐字一致。
  • 命中记录可用独立 Python 脚本从助记词复算验证：本轮 ETH 47/47、BTC 2/2、TRX 7/7 全部 ok，0 mismatch。

链前缀规则期望难度备注

安全须知 / SECURITY

这工具输出的是真链上密钥。命中的那一刻，hits 文件就是你的钱包本身——怎么对钱包，就怎么对它。

⚠ 红线

  • hits 文件是明文助记词 + 私钥：放私有目录，别进云同步盘、别放共享目录、别截图发群。
  • 工具输出的任何内容不要粘贴到在线工具或聊天窗口——粘出去就等于交出资产。
  • Windows 上 hits 文件无法 chmod 0600（源码已跳过该调用），目录权限要自己管好。
  • 只对自己拥有 / 控制的地址做 vanity，不要拿它做他人地址的碰撞搜索。

✓ 设计上的保障

  • secret 不打印、不落明文日志：.eth_vanity_secret 等 32B 文件首次运行自动生成，只影响序列可复现性，丢了不影响用 hits 里的助记词恢复钱包，仍建议离线备份。
  • 命中即落盘：无缓冲追加写入，Ctrl+C 强杀也不丢已命中记录。
  • 可独立验证：selftest / BIP39 标准向量 / Python 复算脚本三重锚点，不用信任作者口头数字。
  • 已知限制写明在 README：P2TR 为原始 x-only 编码、非 BIP86 tweak 地址，往 bc1p 收大额前先看第 4 节说明。
